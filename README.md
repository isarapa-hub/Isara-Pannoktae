[![JP TRIP Demo Video](https://img.youtube.com/vi/tTUqYYi1lLY/maxresdefault.jpg)](https://youtu.be/tTUqYYi1lLY)
## วิธีติดตั้งและรัน

1. **ฐานข้อมูล** (XAMPP / phpMyAdmin) เปิดฐานข้อมูล `project_jp` แล้วรันตามลำดับ
   1. `sql/01_migration.sql` – เพิ่ม `province` ให้ที่พัก, กันรายการโปรดซ้ำ, ขยายคอลัมน์รูปโปรไฟล์ (รัน **ครั้งเดียว**)
   2. `sql/02_seed_data.sql` – ข้อมูลตัวอย่างจังหวัดละ 5 รายการ x 3 หมวด และแก้เวลาเปิด-ปิดวัดเซนโซจิ (รัน **ครั้งเดียว**)
2. **Backend**
   ```
   cd api2
   npm install
   npm start        # http://localhost:5000
   ```
   ตั้งค่าได้ผ่าน environment variable (ไม่ตั้งก็ใช้ค่าเดิมของ XAMPP): `DB_HOST DB_USER DB_PASSWORD DB_NAME PORT JWT_SECRET`
   *ก่อนใช้งานจริงควรตั้ง `JWT_SECRET` เป็นค่าสุ่มของตัวเอง*
3. **Frontend**
   ```
   cd "Web Application JP_Trip"
   npm install
   npm run dev
   ```
   ถ้า backend ไม่ได้อยู่ที่ `http://localhost:5000` ให้คัดลอก `.env.example` เป็น `.env` แล้วแก้ `VITE_API_URL`

## สิ่งที่แก้ไข / เพิ่ม

**แก้บั๊ก**
- SQL `ORDER BY` ใน `/places/:category` ที่ทำให้หน้า Admin โหลดตารางไม่ได้
- หน้าค้นหาดึงเฉพาะสถานที่ท่องเที่ยว → ตอนนี้ค้นทั้ง 3 หมวด ตัวกรองหมวดหมู่/จังหวัด/ราคาใช้ได้จริง และ field ของข้อมูลเหมือนกันทุกหมวด
- ชื่อจังหวัดเป็นชุดเดียวกันทั้งระบบ (โตเกียว คานางาวะ ชิบะ ไซตามะ อิบารากิ โทจิงิ กุนมะ)
- ลิงก์ `/plan` `/profile` ไม่มีหน้า, หน้ารายการโปรดค้นโหลดเมื่อไม่ได้ล็อกอิน, ProfilePage ใช้ localStorage ผิดที่

**ความปลอดภัย**
- Login ส่ง token (JWT) ทุก endpoint ของ Admin ตรวจสิทธิ์ที่ server (ไม่ใช่แค่ใน React)
- สมัครสมาชิกตรวจรูปแบบอีเมลและความยาวรหัสผ่านฝั่ง server
- ตั้งค่าฐานข้อมูลผ่าน environment variable ได้

**ฟีเจอร์ใหม่**
- หน้ารายละเอียดสถานที่ `/place/:category/:id` พร้อมแกลเลอรีรูป
- แผนที่ (Google Maps แบบ embed ไม่ต้องใช้ API key) และปุ่มนำทาง
- รายการโปรดใช้ฐานข้อมูลจริง (หัวใจในหน้าแรก / ค้นหา / รายละเอียด)
- หน้าโปรไฟล์: แก้ชื่อ อีเมล รูป และเปลี่ยนรหัสผ่าน
- หน้าวางแผนการเดินทาง: สร้าง/แก้ไข/ลบแผน เลือกสถานที่ตามวัน (จากการค้นหาหรือรายการโปรด)
- หน้าแรก: ช่องค้นหาส่งค่าไปหน้า Search, สถานที่ยอดนิยมมาจากฐานข้อมูล, ลิงก์ footer ใช้งานได้
- Admin: เพิ่ม/แก้ไข/ลบสถานที่ (พิกัด รูป แกลเลอรี), หน้าจัดการสมาชิก (เปลี่ยนสิทธิ์/ลบ), แดชบอร์ดแสดงสถิติครบทุกหมวด

**ไฟล์ที่ลบ (โค้ดที่ไม่ได้ใช้งาน):** `AuthPage.jsx`, `src/AdminRoute.jsx`, `connectAPI/callproject_jp.js`

## ข้อควรทราบ
- ข้อมูลตัวอย่าง: **พิกัดและราคาเป็นค่าประมาณ** ไม่มี `image_url` (ระบบใช้รูปสำรองให้) ควรตรวจและใส่ลิงก์รูปจริงในหน้า Admin
- ปุ่ม Login with Google ยังไม่เปิดใช้ (ต้องมี Google Client ID) จะแจ้งเตือนเมื่อกด
- รหัสผ่านของบัญชี admin เดิมในฐานข้อมูลยังใช้ได้ตามเดิม (เก็บแบบ bcrypt)
